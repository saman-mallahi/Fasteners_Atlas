# Fastener Engineering Atlas v1.0

## New-repository production baseline

This release resets the repository version to **1.0.0** while carrying forward the expanded database scope planned for the previous development stage.

### Database expansion
- Expanded standards library across ISO, ASTM, ASME, SAE, API, EN, JIS and legacy DIN references.
- Expanded materials and grades including pressure bolting, structural grades, stainless steels, duplex/super-duplex, nickel alloys and titanium.
- Expanded fastener families covering bolts, screws, studs, nuts, washers, anchors, lifting hardware and structural assemblies.
- Expanded coating/finish references with engineering risks.
- Expanded compatibility matrix.
- Expanded engineering warnings covering preload retention, joint separation, thread engagement, thermal effects, flange rotation and process risks.
- Expanded industry/application taxonomy.
- 239 existing thread records retained as the thread baseline.

### Important
This is an engineering reference/screening database, not a replacement for purchased standards, design codes, manufacturer data, MTCs or engineering approval. Values that are edition-, diameter-, product-form- or condition-dependent must be verified against the governing source.


### Maintenance update included in v1.0 package
- Fixed corrupted Metric Trapezoidal thread designations (Tr12×3 through Tr40×7).
- Expanded all coating records with engineering-level process summaries, engineering-use notes, risks and external references.
- Added direct hyperlinks to relevant ISO/ASTM references where available.
- Added AI-made / use-with-discretion disclaimer to the README and site footer.
- Improved mobile thread cards so long designations wrap cleanly instead of breaking the layout.
